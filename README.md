# 🌿 Save Forests — Protect Nature, Preserve Life

**Save Forests** is a responsive environmental awareness website dedicated to promoting forest conservation, protecting biodiversity, and encouraging sustainable living.

The website highlights the importance of forests, raises awareness about environmental threats, and inspires individuals to take small but meaningful steps toward a greener future.

## 🌍 Overview

Forests play a vital role in maintaining ecological balance, supporting wildlife, regulating the climate, and sustaining human life. Save Forests aims to communicate their importance through a clean, modern, and user-friendly website.

## ✨ Features

- **Modern Landing Page:** An impactful hero section with forest photography and a conservation message.
- **Why Forests Matter:** Highlights the importance of climate balance, wildlife habitats, water, soil, and human well-being.
- **Environmental Challenges:** Introduces deforestation, forest fires, and habitat loss.
- **Our Mission:** Presents practical approaches to forest conservation and environmental awareness.
- **Green Pledge Interaction:** An interactive button that encourages visitors to support a greener future.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Mobile Navigation:** Interactive navigation menu for smaller screens.
- **Conservation Resources:** Links to established environmental organizations.
- **Accessible Interface:** Includes semantic HTML, keyboard focus indicators, and reduced-motion support.

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic content
- **CSS3** — Styling, responsive layouts, transitions, and visual design
- **JavaScript** — Navigation interactions, pledge button, and dynamic copyright year
- **Google Fonts** — Manrope and DM Sans typography
- **Unsplash** — Forest photography

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/narbiya132/Save-Forest.git
```

### 2. Open the project

```bash
cd Save-Forest
```

### 3. Run the website

Open `index.html` in your browser.

For a better development experience, open the folder in Visual Studio Code and use the Live Server extension.

No framework, package installation, or build process is required.
